# Abishek D — Developer Portfolio

Personal portfolio built with React, GSAP, and Vite. Showcases projects, skills, journey, and certifications.

## Tech Stack

- **React 19** + **Vite 8**
- **GSAP 3** — ScrollTrigger, Observer, Flip, SplitType animations
- **Framer Motion** — page transitions and micro-interactions
- **Tailwind CSS 4**
- **Three.js** / React Three Fiber — 3D elements

## Features

- GSAP scroll-driven animations (scrub, pin, stagger)
- SplitType word/char text reveals on scroll
- Scramble text effect on nav hover
- Circular orbit profile animation in hero
- Paper plane tied to scroll direction
- FLIP card expand/collapse in Projects section
- Boot sequence intro
- Resume modal with iframe embed
- Smooth scroll via Lenis
- Fully responsive

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── components/     # All page sections and UI components
├── data/           # Projects, certs, timeline data
├── hooks/          # Custom hooks (useTextReveal, useScrollProgress, etc.)
├── assets/         # Images
└── styles/         # Global CSS
```
