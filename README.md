# Abishek D — Developer Portfolio

Personal portfolio built with React, GSAP, and Vite. Showcases projects, skills, journey, and certifications.


## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── components/     # All page sections and UI components
├── data/           # Projects, certs, timeline data
├── hooks/          # Custom hooks (useTextReveal, useScrollProgress, etc.)
├── assets/         # Images
└── styles/         # Global CSS
```
